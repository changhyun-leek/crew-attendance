# 새벽이슬 청소년부 출석관리 정식 사용설명서

대상: 생명샘동천교회 새벽이슬 청소년부 크루교사, 임원교사, 보조교사

운영 주소: https://changhyun-leek.github.io/crew-attendance/

## 1. 가장 빠른 시작

1. 데스크톱의 `새벽이슬 출석관리` 바로가기를 더블클릭합니다.
2. 설명서나 관리 파일이 필요하면 `새벽이슬 출석관리 안내` 폴더를 엽니다.
3. 첫 화면에서 `크루교사`, `임원교사`, `보조교사` 중 본인의 역할을 누릅니다.
4. 크루교사와 임원교사는 이름을 선택하고 PIN을 입력합니다.
5. 개인 기기에서는 로그인이 최대 30일 유지됩니다. 공용 기기에서는 반드시 로그아웃합니다.

### 휴대폰·컴퓨터에 앱처럼 설치하기

사이트 왼쪽 아래의 `앱 설치` 버튼을 누르면 현재 기기에 맞는 설치 순서가 표시됩니다. 설치 후에는 홈 화면·바탕 화면·시작 메뉴의 새벽이슬 아이콘을 눌러 바로 실행할 수 있습니다.

- **안드로이드**: Chrome 또는 Samsung Internet으로 사이트를 열고 `앱 설치`를 누릅니다. 자동 설치 버튼이 없으면 브라우저 메뉴의 `앱 설치` 또는 `홈 화면에 추가`를 선택합니다.
- **아이폰·아이패드**: Safari로 사이트를 열고 `공유` → `홈 화면에 추가` → `추가`를 누릅니다.
- **Windows·Mac 컴퓨터**: Chrome 또는 Edge 주소창의 설치 아이콘을 누릅니다. 보이지 않으면 브라우저 메뉴에서 `앱 설치`를 선택합니다.
- **카카오톡 링크**: 카카오톡 안에서는 설치가 제한될 수 있습니다. 우측 상단 메뉴에서 `다른 브라우저로 열기`를 선택한 뒤 설치합니다.

설치해도 교사 권한과 PIN은 그대로 유지됩니다. 개인 기기에서는 자동 로그인을 사용할 수 있고, 다른 교사가 같은 기기를 쓸 때는 먼저 로그아웃합니다. 새 버전 알림이 나타나면 출석 입력을 마친 뒤 `업데이트`를 누릅니다.

### 휴대폰 출석 알림 켜기

크루교사는 로그인 후 출석 화면 아래의 `휴대폰 출석 알림`에서 `알림 켜기`를 한 번 누릅니다. 이후 임원교사가 보내는 출석 독려 알림을 앱이 닫힌 상태에서도 받을 수 있습니다.

- **아이폰·아이패드**: 반드시 먼저 홈 화면에 설치하고, 설치된 새벽이슬 아이콘으로 실행한 뒤 알림을 켭니다.
- **안드로이드**: 설치된 앱 또는 Chrome에서 알림을 켤 수 있습니다.
- 휴대폰에서 알림 허용 질문이 나오면 `허용`을 누릅니다.
- 알림이 필요 없으면 같은 자리에서 `알림 끄기`를 누릅니다.

### 라이트·다크 화면 바꾸기

첫 화면 오른쪽 위, 출석 화면 상단 또는 임원 화면 왼쪽 메뉴의 `화면 모드`를 누릅니다.

- **기기 설정대로**: 휴대폰·컴퓨터의 밝기 설정을 자동으로 따라갑니다.
- **밝게 보기**: 밝은 장소에서 읽기 쉬운 라이트 모드입니다.
- **어둡게 보기**: 어두운 장소에서 눈부심을 줄이는 다크 모드입니다.

선택한 화면 모드는 해당 기기에 저장됩니다. 보라색 십자가·체크 아이콘은 휴대폰 설치용이며, 모니터 모양 아이콘은 컴퓨터 브라우저와 바로가기에서 사용됩니다.

## 2. 역할별 차이

- **크루교사**: 담당 크루 출석, 결석 사유·연락 상태·학생 비고, 학생 추가와 상태 관리
- **보조교사**: 이름만 입력해 선택 크루의 오늘 출석과 당일 사유만 수정
- **임원교사**: 전체 출석과 비고 확인, 내보내기, 공지·임시 조사, 크루·교사·학생·PIN 관리

## 3. 크루교사 출석체크

1. `크루교사`를 누릅니다.
2. 이름을 직접 누르거나 `이름 검색`에 이름 일부를 입력합니다.
3. 4~6자리 PIN을 입력하고 확인 버튼을 누릅니다.
4. 화면 상단 날짜가 이번 주 주일로 자동 설정되었는지 확인합니다. 과거 기록을 수정할 때만 날짜를 직접 바꿉니다.
5. 학생마다 `출석` 또는 `결석`을 누릅니다.
6. 결석 이유나 연락 결과가 있으면 `사유·비고`를 누릅니다.
7. 임원이 만든 임시 항목이 있으면 학생별 값을 선택합니다.
8. 미체크 인원이 0명인지 확인하고 `보고 문구 복사`를 사용합니다.

저장 표시는 `저장 중 → 저장됨` 순서로 바뀝니다. 인터넷 연결 경고나 저장 실패가 보이면 저장된 것으로 판단하지 않습니다.

### 내 PIN 변경

출석 화면 아래의 `내 PIN 변경`을 누르고 현재 PIN, 새 PIN, 새 PIN 확인을 입력합니다. 다음 로그인부터 새 PIN을 사용하며 숫자 6자리를 권장합니다. PIN을 잊은 경우에는 임원교사가 초기화합니다.

### 학생 관리

- 새 학생은 출석 화면의 학생 관리에서 추가합니다.
- 장기결석자는 `장기결석`으로 전환하고 복귀 시 `활동`으로 되돌립니다.
- 더 이상 크루에 속하지 않는 학생은 삭제하지 않고 `퇴실`로 처리합니다.
- 과거 출석 기록은 학생 상태가 바뀌어도 유지됩니다.

## 4. 보조교사 출석체크

1. 첫 화면에서 `보조교사`를 누릅니다.
2. 출석할 크루를 선택합니다.
3. 본인 이름을 두 글자 이상 입력합니다.
4. 오늘 출석·결석, 결석 사유, 연락 상태, 임시 확인 항목만 입력합니다.
5. 이름을 잘못 입력했으면 화면 상단 이름에서 수정합니다.

보조교사는 과거 출석, 지속 학생 비고, 학생 관리, 다른 크루, 내보내기 기능을 볼 수 없습니다. 입력한 이름과 이름 정정 내역은 변경 기록에 남습니다.

## 5. 결석 사유·연락 상태·학생 비고

- **결석·특수 사유**: 해당 출석일에만 필요한 사유. 예: 감기, 가족 일정
- **연락 상태**: 아직 연락 안 함 / 연락 안 됨 / 연락 완료 / 기타
- **학생 비고**: 임원이 앞으로도 계속 알아야 할 내용. 예: 장학금 서류 확인, 지속 상담 필요
- **임시 확인 항목**: 임원이 정한 기간에만 확인하는 조사. 예: 수련회 신청 / 미신청 / 고려중

민감한 개인정보는 사역에 필요한 최소 범위로만 기록합니다. 학생 비고에 주민등록번호, 계좌 비밀번호, 교사 PIN 같은 정보를 적지 않습니다.

## 6. 임원교사 전체 현황과 내보내기

1. `임원교사`를 누르고 임원 계정과 PIN으로 로그인합니다.
2. `전체 현황`에서 운영 크루, 학생, 출석, 결석, 출석률을 확인합니다.
3. 시작일·종료일·크루·학생·상태·비고 필터를 설정하고 `조회`를 누릅니다.
4. 출석 상세는 크루별로 접혀 표시됩니다. 크루 제목에서 출석·결석·미체크 인원과 출석률을 먼저 확인하고 필요한 크루만 펼칩니다.
5. 노란색 행과 `확인 필요` 표시는 사유, 연락 안 됨, 학생 비고가 있는 학생입니다. 출석 학생의 결석 사유·연락 칸은 `-`로 표시됩니다.

### 출석 독려 알림 보내기

`전체 현황` 위쪽에서 이번 주 크루별 체크 상태와 교사의 알림 기기 수를 확인합니다. 아직 완료하지 않은 크루의 `독려 알림 보내기`를 누르면 담당교사의 휴대폰에 알림이 갑니다. 같은 크루에는 실수로 반복 발송되지 않도록 30분에 한 번만 보낼 수 있습니다. `교사 알림 꺼짐`이 보이면 담당교사에게 먼저 휴대폰 알림을 켜 달라고 안내합니다.

내보내기 버튼:

- **TXT**: 단톡방이나 문서에 붙이기 쉬운 보고용 문구
- **CSV**: Windows Excel에서 한글이 깨지지 않는 UTF-8 BOM 파일
- **Excel용 표 복사**: 복사 후 Excel의 첫 번째 셀에 붙여넣기

## 7. 임원교사 관리 기능

### 크루 관리

- 크루명과 운영 연도를 입력해 새 크루를 만듭니다.
- 크루 행에서 담당교사 이름을 선택하고 `배정 저장`을 누릅니다.
- 크루 운영 종료는 확인창을 거친 뒤 처리합니다. 과거 기록은 유지됩니다.

### 교사 관리

- 교사 이름, 처음 사용할 PIN, 역할을 입력해 등록합니다.
- 기존 교사의 새 PIN을 입력하고 `PIN 초기화`를 누릅니다.
- 더 이상 사용하지 않는 계정은 `비활성화`합니다. 필요하면 다시 활성화할 수 있습니다.
- 현재 로그인한 임원 본인 계정은 실수로 비활성화할 수 없습니다.

### 학생 관리

- 학생 이름과 소속 크루를 선택해 등록합니다.
- 학생 이름 검색으로 학생을 빠르게 찾습니다.
- 상태를 활동 / 장기결석 / 퇴실로 변경합니다.
- 다른 크루가 있을 때 이동할 크루를 선택하고 `크루 이동`을 누릅니다.

## 8. 공지·임시 확인 항목·의견함

### 공지 만들기

1. `공지·임시 항목` 메뉴를 엽니다.
2. 종류에서 `공지`를 선택합니다.
3. 제목, 설명, 시작일, 종료일을 입력해 게시합니다.

### 학생별 임시 확인 칸 만들기

1. 종류에서 `학생별 임시 확인 칸`을 선택합니다.
2. 제목과 설명을 입력합니다.
3. 선택지를 쉼표로 구분합니다. 예: `신청, 미신청, 고려중`
4. 필요하면 필수 입력으로 설정하고 게시 기간을 지정합니다.

기간이 끝나면 출석 화면에서 자동으로 숨겨지지만 입력된 응답은 보존됩니다.

### 오류·개선 의견

- 교사는 화면 아래 `오류·개선 의견 보내기`로 의견을 보냅니다.
- 임원은 `오류·개선 의견`에서 `새 의견 → 확인 중 → 완료`로 처리 상태를 관리합니다.

## 9. 로그인·로그아웃·PIN 안전수칙

- 개인 휴대폰과 개인 컴퓨터는 최대 30일간 로그인이 유지됩니다.
- 공용 휴대폰·교회 공용 컴퓨터에서는 사용 후 반드시 로그아웃합니다.
- PIN을 5회 연속 잘못 입력하면 10분간 로그인할 수 없습니다.
- 본인 PIN은 출석 화면의 `내 PIN 변경`에서 현재 PIN 확인 후 변경합니다.
- PIN을 잊으면 임원교사에게 초기화를 요청합니다.
- PIN, Supabase 비밀키, 관리자 초기 코드는 단톡방이나 화면 캡처에 남기지 않습니다.

## 10. 문제가 생겼을 때

- **인터넷 연결 경고**: 현재 내용을 임시 메모하고 연결 복구 후 다시 저장
- **저장 실패**: 학생과 항목을 확인하고 재시도한 뒤 의견함에 기록
- **PIN 잠김**: 10분 기다리거나 임원에게 문의
- **보조교사 이름 오류**: 화면 상단 이름에서 수정
- **긴급 출석 업무**: 임원에게 알리고 종이·단톡방에 임시 기록 후 시스템에 입력
- **화면이 예전 모습**: 브라우저 새로고침 또는 `Ctrl+F5`

오류를 신고할 때는 역할, 화면 이름, 누른 버튼 순서, 기대한 결과, 실제 결과, 발생 시각을 적습니다. 학생 개인정보와 PIN은 가리고 화면을 캡처합니다.

## 11. 데스크톱과 수정 요청

데스크톱의 `새벽이슬 출석관리 안내` 폴더에는 다음 항목이 있습니다.

- 운영 사이트 바로가기
- 이 사용설명서
- 프로그램 관리 폴더 바로가기
- 오류·개선 요청 작성 예시

수정 요청은 이 Codex 대화에서 `새벽이슬 출석관리에서 ○○를 수정해줘`라고 말하면 됩니다. 먼저 데모 화면에서 확인하고 테스트가 성공한 변경만 운영 사이트에 배포합니다.

## 12. 운영 전후 체크리스트

- 날짜와 크루명이 올바른가
- 모든 학생이 출석 또는 결석으로 체크되었는가
- 결석 사유와 연락 상태가 필요한 학생에게 입력되었는가
- 임시 확인 항목을 빠뜨리지 않았는가
- 저장 실패나 인터넷 경고가 없는가
- 공용 기기라면 로그아웃했는가
- 임원은 비고 있는 학생과 의견함의 새 항목을 확인했는가
