# 새벽이슬 청소년부 출석관리 사용설명서

생명샘동천교회 새벽이슬 청소년부의 크루교사, 임원교사, 보조교사가 함께 사용하는 출석관리 시스템입니다.

## 처음 화면

사이트를 열면 세 가지 버튼이 나타납니다.

1. **크루교사**: 담당 크루 출석체크, 학생 관리, 과거 출석 확인
2. **임원교사**: 전체 현황, 공지, 임시 조사, 교사·크루·학생과 의견함 관리
3. **보조교사**: 개인 계정 없이 이름을 입력하고 선택한 크루의 오늘 출석만 체크

한 번 로그인한 크루교사와 임원교사는 개인 기기에서 최대 30일 동안 로그인이 유지됩니다. 공용 기기에서는 반드시 `로그아웃`을 누릅니다.

## 크루교사 사용법

1. `크루교사`를 누릅니다.
2. 이름을 직접 누르거나 검색창에 이름을 입력합니다.
3. 숫자 PIN 4~6자리를 입력합니다.
4. 학생별 `출석` 또는 `결석`을 누릅니다.
5. 결석 이유, 연락 상태, 학생 비고가 있으면 `사유·비고`를 누릅니다.
6. 임원이 요청한 임시 항목(예: 수련회 참석)을 선택하고 저장합니다.
7. 체크가 끝나면 `보고 문구 복사`로 단톡방 보고용 문구를 복사합니다.

`학생 비고`에는 장학금 신청, 지속적으로 확인해야 할 가정 상황처럼 임원이 계속 알아야 할 내용을 기록합니다. 단순한 당일 결석 이유는 `결석·특수 사유`에 기록합니다.

## 보조교사 사용법

1. 첫 화면에서 `보조교사`를 누릅니다.
2. 출석할 크루를 선택하고 본인 이름을 입력합니다.
3. 해당 크루의 오늘 출석만 체크합니다.
4. 필요한 경우 당일 결석 사유와 연락 상태, 임시 확인 항목을 입력합니다.
5. 이름을 잘못 입력했으면 화면 상단 이름을 눌러 수정합니다.

보조교사는 과거 출석, 학생의 지속 비고, 다른 크루 자료, 내보내기 기능을 볼 수 없습니다. 모든 변경에는 입력한 보조교사 이름이 남습니다.

## 임원교사 사용법

### 전체 현황과 출석 기록

- 날짜, 크루, 학생, 출석 상태, 체크자, 비고 여부로 검색합니다.
- 노란색 행과 `확인 필요` 표시는 결석 사유, 연락 안 됨, 학생 비고가 있는 학생입니다.
- 우측 상단에서 TXT, UTF-8 BOM CSV, Excel용 표 복사를 사용할 수 있습니다.

### 공지와 임시 확인 항목

- `공지·임시 항목`에서 교사 출석 화면에 보일 공지를 게시합니다.
- 학생별로 잠시 필요한 칸은 `학생별 임시 확인 칸`을 선택합니다.
- 예: 제목 `수련회 참석`, 선택지 `신청, 미신청, 고려중`, 게시 기간 지정
- 게시 기간이 끝나면 출석 화면에서는 자동으로 숨겨지지만 응답 기록은 보존됩니다.

### 오류·개선 의견

- 모든 로그인 화면의 `오류·개선 의견 보내기`로 교사가 의견을 보낼 수 있습니다.
- 임원은 `오류·개선 의견` 메뉴에서 `새 의견 → 확인 중 → 완료`로 처리 상태를 관리합니다.

### 교사·크루·학생 관리

- 교사 또는 임원을 등록하고 PIN을 초기화합니다.
- 크루를 만들고 운영 연도와 담당교사를 배정합니다.
- 학생 추가, 크루 이동, 장기결석과 퇴실 상태를 관리합니다.
- 학생을 직접 삭제하지 않아 과거 출석 기록이 유지됩니다.

## 출석 정보 작성 기준

- **결석·특수 사유**: 해당 날짜에만 필요한 이유
- **연락 상태**: 아직 연락 안 함 / 연락 안 됨 / 연락 완료 / 기타
- **학생 비고**: 임원이 앞으로도 계속 알아야 할 사항
- **임시 확인 항목**: 임원이 정한 기간 동안만 교사에게 요청하는 조사

민감한 개인정보는 꼭 필요한 범위에서만 기록하며, 공용 기기 사용 후에는 로그아웃합니다.

## 문제가 생겼을 때

1. 인터넷 연결 경고가 보이면 연결이 복구될 때까지 저장 완료로 판단하지 않습니다.
2. 저장 실패가 표시되면 새로고침 전에 학생 이름과 항목을 확인합니다.
3. `오류·개선 의견 보내기`에 역할, 화면, 한 행동, 기대한 결과를 적습니다.
4. 긴급한 출석 업무는 임원에게 알리고 종이 또는 단톡방 기록을 임시로 남깁니다.
